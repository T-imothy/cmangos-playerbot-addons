CMANGOS BOT MANAGER — TBC v1.0
==============================

TBC Community Edition
Designed by Tim

A usability-focused interface redesign for the native CMaNGOS MangosBot
addon for World of Warcraft 2.4.3.

IMPORTANT
---------
This package uses the original TBC addon as its backend.

It preserves:
• TBC-specific PlayerBots commands
• TBC class strategies and abilities
• Original server queries
• Original button handlers and tooltips
• Live green active-state borders

INTERFACES
----------
/bot
  Opens the compact party roster and quick controls.

/mbp
  Opens or closes the same compact quick-control interface.

Select a bot
  Opens the detailed bot-management panel.

DETAILED TABS
-------------
Quick
Combat
Utility
Class

FEATURES
--------
• Compact two-column roster
• Dark framed bot cards
• Organized quick controls
• Narrow detailed panel
• Live original-addon status
• Anti-blinking partial-update handling
• Manual X close button
• Community-neutral CMaNGOS branding

INSTALLATION
------------
1. Back up your existing TBC Interface\AddOns\mangosbot folder.
2. Replace it with the mangosbot folder from this package.
3. Log in and test /bot.
4. Select a bot and verify all four detailed tabs.

This is the TBC build. Do not install it in Classic or WotLK.
